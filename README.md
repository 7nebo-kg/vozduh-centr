# Воздух Центр

Создатель приложения: Алексей Евдокимов.

Датчик установлен по адресу: г. Бишкек, ул. Огонбаева, д. 222.

[Скачать последнюю версию APK](https://github.com/evdokimov1996/vozduh-centr/releases/latest/download/Vozduh-Centr.apk)

Приложение показывает семь показателей уличного датчика через интернет и графики за24часа. Обновление показаний — раз в минуту, пока приложение открыто. При потере связи старые данные отмечаются и перестают показываться как свежие.

Совместимость: Android6.0 и новее, обновлённый Android System WebView; один APK для ARM32/ARM64/x86. Root и учётная запись не нужны. Интерфейс подстраивается под экран и размер текста. Не все модели телефонов были физически испытаны.

Для установки скачайте APK, откройте его и подтвердите установку Android. Новые версии приложение находит автоматически; установка требует подтверждения Android. Доступны кнопки отправки ссылки и самого APK через системное меню, включая WhatsApp.

Репозиторий содержит публичные установочные файлы и метаданные выпуска. Показания датчика — информационные измерения по указанному адресу.
